# Leitor de documentos para Windows

[**Baixar a versão mais recente**](https://github.com/iasupremaia9-jpg/leitor-documentos-downloads/releases/latest)

Baixe `Instalar-Leitor-7.9.exe`, abra e clique em **Instalar**. Use o atalho na Área de Trabalho ou no menu Iniciar.

## Leitura rápida primeiro

A versão 7.9 mostra os primeiros dados antes da leitura adicional. Você já pode conferir, corrigir e copiar enquanto o aplicativo tenta completar campos ausentes. Suas correções são preservadas. Quando todos os campos já estão preenchidos, a etapa adicional é dispensada.

## Marcador

Arraste sobre uma linha da imagem e escolha **Ler como** no campo desejado. Na versão 7.9, o marcador funciona durante a leitura adicional. Campos marcados e correções manuais são preservados quando a leitura automática termina.

## Frente e verso

Clique em **Abrir frente e verso**. Selecione um arquivo ou segure **Ctrl** para selecionar dois arquivos do mesmo documento. Alterne as imagens na lista acima da visualização. Dados conflitantes ficam para conferência.

## Leitura adicional

Windows OCR, Tesseract e RapidOCR/PP-OCRv6 trabalham localmente. Modelos e componentes acompanham o instalador de aproximadamente 95 MB. Não é necessário instalar Python.

Esta atualização melhora o tempo até o primeiro resultado; não garante maior precisão. Documentos danificados e filiação sem indicação de mãe/pai podem exigir preenchimento manual. Confira sempre com o original.

## Atualizações

A partir da versão 7.5, o aplicativo verifica atualizações ao abrir. Você também pode clicar em **Buscar atualizações → Atualizar**, confirmar o download e clicar em **Instalar**. Copie os dados em uso antes de atualizar.

Requer Windows 10/11 de 64 bits, .NET Framework e Microsoft Visual C++ 2015–2022 x64. Licenças acompanham o instalador.

Os documentos são lidos no computador. A consulta de atualizações acessa o GitHub sem enviar documentos ou campos reconhecidos.

Este repositório contém somente informações de distribuição e instaladores. O código-fonte e os documentos de teste não são publicados aqui.
