# Leitor de documentos para Windows

[**Baixar a versão mais recente**](https://github.com/iasupremaia9-jpg/leitor-documentos-downloads/releases/latest)

Na página, clique no arquivo `Instalar-Leitor-7.6.exe`, abra e clique em **Instalar**. Use o atalho na Área de Trabalho ou no menu Iniciar.

A partir da versão 7.5, o aplicativo verifica atualizações ao abrir. Você também pode clicar em **Buscar atualizações**. Havendo uma nova versão, clique em **Atualizar**, confirme o download e clique em **Instalar** no instalador. Copie os dados em uso antes de atualizar.

Na versão 7.6, você também pode arrastar sobre uma linha da imagem e escolher o campo no menu para tentar uma leitura localizada. Os resultados são sugestões editáveis; imagens danificadas podem exigir preenchimento manual.

Requer Windows 10/11 de 64 bits, .NET Framework e Microsoft Visual C++ 2015–2022 x64. Os componentes de leitura e suas licenças acompanham o instalador.

Os documentos são lidos no computador. A consulta de atualizações acessa o GitHub sem enviar documentos ou campos reconhecidos. Confira os dados extraídos no original.

Este repositório contém somente informações de distribuição e instaladores. O código-fonte e os documentos de teste não são publicados aqui.
